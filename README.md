# rs-responder
Simple Slack-Bot with a help command, ping command, and an echo command.

<img width="1255" height="300" alt="image" src="https://github.com/user-attachments/assets/c8ccea66-597f-45b7-aca5-ac30943e995f" />
Try it by timing in one of the command above into the Hack Club Slack:  https://app.slack.com/client/E09V59WQY1E/C0P5NE354

The help command (/rs-responder-help) lists the commands seen in the picture above
The ping command (/rs-responder-ping) pings the bot and sends the respond time back.
The echo command (/rs-responder-echo [input]) takes an input and has the bot respond back with it.

This project was made with the Node.js and Bolt libraries connecting to Slack and can be used at any time thanks to Hack Club's Nest!
